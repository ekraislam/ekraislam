## 🌟 Featured Projects

A selection of projects spanning AI/ML, software development, research exploration, and interactive computer science tools.

### 🛡️ CitationGuard AI
**Evidence-aware citation verification and claim–evidence analysis**

Explores how claims can be compared against supporting evidence to identify supported, contradicted, and insufficiently supported statements.

- Focus: NLP, evidence grounding, and citation verification
- Technologies: Python, Transformers, PubMedBERT
- Repository: [CitationGuard AI](https://github.com/ekraislam/citationguard-ai)

### 🌾 RiceGuard AI
**Rice leaf disease classification and visual explainability**

A computer vision project exploring rice leaf disease classification and visual explanations of model predictions.

- Focus: Image classification and explainable AI
- Technologies: Python, PyTorch, ResNet18, Grad-CAM
- Repository: [RiceGuard AI](https://github.com/ekraislam/rice-leaf-disease-detection)

### 🌌 Event Horizon 3D
**An interactive black hole and space simulation**

An interactive web graphics project exploring black-hole-inspired visuals and immersive space environments.

- Focus: 3D graphics and interactive simulation
- Technologies: JavaScript, Three.js, WebGL, GLSL
- Repository: [Event Horizon 3D](https://github.com/ekraislam/Event-Horizon-)

### 💻 OScope
**Interactive operating system concepts and simulations**

A software project focused on visualizing operating system concepts through interactive simulators.

- Focus: Operating systems and computer science education
- Technologies: React, TypeScript
- Repository: [OScope](https://github.com/ekraislam/oscope)

### 🔬 Error Detection & Correction Simulator
**An interactive data communication learning tool**

A project for exploring error detection and correction methods used in data communication.

- Focus: Networking concepts and protocol visualization
- Topics: Parity, checksum, CRC, Hamming code, and stuffing methods
- Repository: [Error Detection & Correction Simulator](https://github.com/ekraislam/error-detection-correction-simulator)

### 📄 Bangla Document Intelligence
**Bangla and English document OCR and search**

Explores text extraction and document search for Bangla and English documents.

- Focus: OCR, document processing, and information retrieval
- Technologies: Python, EasyOCR, Streamlit, OpenCV
- Repository: [Bangla Document Intelligence](https://github.com/ekraislam/bangla-document-intelligence)

### 📅 UniPlanner
**A student-focused academic planner**

A planner project designed to help students organize academic deadlines and tasks.

- Focus: Productivity and academic planning
- Technologies: React, TypeScript, Progressive Web App
- Repository: [UniPlanner](https://github.com/ekraislam/uniplanner)

### 🌱 Momin Agro
**A farm management application**

A practical software project focused on supporting dairy farm record-keeping and management workflows.

- Focus: Agricultural software and practical record management
- Repository: [Momin Agro](https://github.com/ekraislam/agro-farm-management)

### 🤝 LifeLine Charity
**A charity and community-support platform**

A web development project centered on charity and NGO-related workflows.

- Focus: Web applications and community support
- Repository: [LifeLine Charity](https://github.com/ekraislam/Lifeline-Charity)

### 🦋 Butterfly Species Classification
